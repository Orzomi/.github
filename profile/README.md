# Orzomi

**Orzomi builds its own products for problems worth solving.**

We find a problem people live with every day, then build the product that fixes it, and we run it ourselves.

### Bartefy
Swap things you don't need for things you do. List an item, browse finds near you, and offer one of yours in exchange. When the owner accepts, you chat and meet to swap.
